# House format for status reports

Every status report in this repository MUST follow this exact structure, with no deviations:

1. The very first line is exactly: `# Status Report`
2. Then exactly these three second-level sections, in this order:
   - `## Highlights`
   - `## Risks`
   - `## Next Steps`

No other top-level (`#`) or second-level (`##`) headings are allowed. Section bodies may contain any
prose or bullet lists.
