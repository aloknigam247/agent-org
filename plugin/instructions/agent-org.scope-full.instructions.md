# Full managed area

Host-only routing: apply the guard in `agent-org.instructions.md` before following this profile.

Route repository code and investigation requests through the configured root. The complete managed area is
recorded in `.github/agent-org/org.json`'s `scope`, independently of any node's current retained domain.
Scope and charter globs are repository-root-relative, not relative to the configuration directory.
